# 设计输入与降级

## 能力与精度阶梯

先识别链接、文件与授权范围，按可用能力选择：官方结构化数据/标注 → 合法导出的 HTML/素材 → 授权浏览器中的目标页面截图 → 用户提供截图与交互说明。不要宣称某平台永远没有 MCP；检查当时已安装工具及官方契约。

### 墨刀

- 先读当前 modao 工具的描述和 schema，不假定用户已装 MCP，不要求特定网关。
- 已观察到某版本 `export_proto_to_html` 要求完整 `/proto/design/{id}` 设计页地址；`axbox/share/{token}` 不能直接当作该工具的 project_url。分享 token 也不是 project_cid。
- 若有真实 project_cid/页面 key，用结构读取工具按页面获取；没有就用官方项目目录或用户提供的信息定位，禁止猜 ID。
- 账号创建项目列表为空，不证明所有分享/团队项目均不可访问。错误“原型 JSON 导出服务暂时不可用”不能区分 ID、权限、平台版本与服务故障；保留原文，明确未确认的原因。
- 如果工具不支持分享页：在用户授权且产品确实提供入口时，复制/另存到有权访问的空间，再使用返回的真实设计页地址。复制会创建资产，不能只为绕过报错擅自执行。并非所有分享页都有克隆按钮。
- HTML 导出返回下载地址时，检查工具对下载主体、登录和有效期的要求；若仅允许用户在已登录浏览器打开，就展示地址，不自行代下载。不执行导出 HTML 内的脚本。
- 工具明确禁止失败后自动重试时遵守；不以 generate/continue_task 替代读取，不意外创建付费任务。

### Figma、MasterGo、即时设计、Pixso 等

优先使用实际可用的官方 MCP、插件或导出。检查账号/文档权限和节点 ID。Figma 本地 Dev Mode 端点常为 `http://127.0.0.1:3845/mcp`，以客户端设置为准；远程认证限制是客户端兼容问题，不代表所有网关都会失败。

### 浏览器降级

仅当链接可授权访问时，使用现有浏览器工具。打开指定页面，查看目标屏幕；必要导航/切换画布可以做，但不修改设计资产。首次预算 1–2 张关键截图，覆盖代表性布局后再决定是否扩展；不要逐屏抓取整个项目。

登录/密码/导出权限不足时停在该边界，说明所需信息，可使用用户提供的截图。截图只能确定可见状态；字号、间距、响应式、隐藏交互、权限状态均需标注为推断。

## 从数据到代码

列出布局层级、文案、tokens、可复用组件、交互和未知状态。先复用工程组件与资产，不能从截图反推不存在的业务规则。验收时对齐视口、字体和数据状态，区分客观偏差与主观设计选择。
