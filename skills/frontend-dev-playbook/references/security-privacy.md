# 安全与隐私

- 前端包和客户端环境变量对用户可见；密钥只能放服务端或受控凭据服务。示例、日志、截图和公开报告均不得泄漏 token/个人信息。
- 外部 HTML、富文本、Markdown、URL 参数不可信。使用框架默认转义；确需 HTML 时用已有可信净化机制，不执行导出页面脚本。
- 路由守卫、按钮隐藏和本地角色字段只改善体验，服务端必须鉴权。不要“修复”401/403为前端跳过权限。
- 依项目的 cookie/CSRF/CSP/跨域方案处理认证，不能普遍建议禁 CSP、allow-origin * 或把令牌长存本地来绕过问题。
- URL 跳转与 postMessage 检查目标/来源，下载文件名和上传内容遵循项目策略。禁止从错误消息把服务端敏感字段展示给所有用户。
- 依赖变化核对来源、版本、lockfile 与许可证；不要执行远程安装脚本仅为完成小功能。
- 埋点先确认授权与事件字典，只采必要字段，处理 consent，避免重复上报和上传用户输入全文。

发现实际问题时给出触发条件、影响范围、最小修复和验证。不要把假设风险扩展成与当前任务无关的大规模审计。
